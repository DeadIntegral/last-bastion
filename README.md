# Last Bastion — 최후의 성채

마왕군에게 대륙 전체를 빼앗기기 직전, 최후의 성채에서 반격을 시작하는 웹 기반 횡스크롤 공성 게임입니다. 왕국군은 배신한 인간군과 고블린·오크·오우거 같은 몬스터, 속박된 정령, 악마 군세를 차례로 돌파해 마왕성으로 진격합니다.

## 실행 방법

Node.js 22.22.2 이상과 Yarn Classic 1.22.22를 사용합니다. 저장소의 `.node-version`은 Cloudflare Pages가 호환되는 Node를 선택하도록 `22.22.2`로 고정되어 있습니다.

```bash
yarn install
yarn dev
```

프로덕션 빌드와 테스트:

```bash
yarn test
yarn balance
yarn lint
yarn build
yarn art:atlas
```

Cloudflare Pages 설정은 빌드 명령 `yarn build`, 출력 경로 `dist`를 사용합니다. Pages v3의 기본 Node 22.16.0은 `jsdom@30.0.1`을 설치할 수 없지만, 루트 `.node-version`이 빌드 환경을 Node 22.22.2로 올립니다. 대시보드에서 별도 `NODE_VERSION`을 설정했다면 `22.22.2` 이상으로 맞추세요.

## 플레이 방법

- 지도는 남서쪽 해안의 최후의 성채에서 시작합니다. 한 장으로 이어진 대륙의 왕도·내륙을 수복하며 북쪽으로 진격하고, 발견한 챕터2 전선은 북동쪽으로 이어집니다. 지역 바로가기와 상하좌우 스크롤로 열린 땅을 살펴볼 수 있습니다.

- 첫 방문에서는 브라우저 언어가 한국어면 한국어, 일본어면 일본어, 그 외에는 영어로 시작합니다. 타이틀 우측 상단과 게임 내 상단 바의 드롭다운에서 `한국어 / English / 日本語`를 선택할 수 있으며, 선택 언어는 세 저장 슬롯과 분리된 브라우저 전역 설정으로 기억됩니다. 번역 리소스는 필요할 때만 불러오며, 일본어 장문이 아직 없으면 영어, 영어도 없으면 한국어 원문을 표시합니다.
- 타이틀 화면에는 서로 독립적인 저장 슬롯 3개가 있습니다. 빈 슬롯은 `새 게임`, 사용 중인 슬롯은 `이어하기 · 내보내기 · 삭제`를 표시합니다. 새 게임은 선택한 슬롯만 초기화하고 전용 16:9 원화·문구 페이드·카메라 움직임·진행 바로 구성된 약 21초의 네 장면 반격 시네마틱을 자동 재생한 뒤 왕국 지도로 이어집니다. 다음 버튼은 없으며 `오프닝 건너뛰기`나 Esc로 즉시 넘어갈 수 있습니다.
- `내보내기`는 비밀번호 입력이나 글자 수 제한 없이 즉시 저장 파일을 다운로드합니다. 앱이 AES-256-GCM 암호화, PBKDF2-SHA-256 210,000회, 저장마다 새 salt·IV, Base64 인코딩과 SHA-256 체크섬을 자동 처리합니다. `저장 파일 가져오기`도 현재 형식은 자동으로 복호화·검증한 뒤 대상 슬롯을 선택하며, 사용 중인 슬롯은 별도 덮어쓰기 확인을 거칩니다. 게임 버전과 저장 스키마 버전도 파일에 함께 기록됩니다. 앱에 포함된 키는 사용자 비밀키가 아니므로 이 형식은 계정급 보안보다 파일 손상 감지와 단순 편집 방지를 위한 것입니다.
- 기존 `last-bastion-profile-v1` 단일 자동 저장은 업데이트 후 슬롯 1로 한 번 자동 이전됩니다. 과거 평문 휴대용 JSON, 원본 상태 JSON, Zustand `{ state, version }` 래퍼도 계속 가져올 수 있지만 새로 내보내는 파일은 암호화 형식만 사용합니다.
- 이전 버전에서 비밀번호로 내보낸 암호화 파일도 계속 가져올 수 있습니다. 이 경우에만 당시 비밀번호가 필요하며 입력 글자 수에 새 제한을 두지 않습니다.
- 새 게임, 저장 가져오기 덮어쓰기, 전체 진행 초기화처럼 되돌리기 어려운 작업은 브라우저 시스템 경고 대신 게임 스타일 모달로 확인합니다. 모달은 Esc 닫기, 안전한 버튼 우선 포커스, Tab 포커스 순환을 지원합니다.
- 타이틀·대륙 지도·관리 시설·결과 화면 사이 이동은 지원 브라우저에서 위치 이동이나 크기 변화 없는 짧은 순수 페이드 전환을 사용합니다. 모션 축소를 요청했거나 View Transition API를 지원하지 않는 환경에서는 애니메이션 없이 즉시 이동하며, 시네마틱 오프닝과 Phaser 전투 진입·이탈은 각자의 렌더링 수명 주기를 보호하기 위해 전환 대상에서 제외합니다.
- 병영과 강화, 영웅의 전당, 성채 기술, 업적 기록, 전쟁 사전, 출석 보상, 수수께끼 상인, 사운드 설정은 왕국 지도의 `왕국 운영` 패널에서 이용합니다. 영웅 숙련은 별도 메뉴가 아니라 영웅의 전당 카드에 통합됩니다. 데스크톱에서는 지도 바깥 왼쪽의 작은 세로 패널, 좁은 화면에서는 지도 위의 압축 도구막대로 표시되며 각 관리 화면과 전투 결과에서 뒤로 가면 왕국 지도로 복귀합니다.
- 신규 기록은 민병대 하나로 시작합니다. 왕국 지도 1~3장을 최초 클리어하면 방패병, 궁수, 창병을 순서대로 획득합니다.
- 캠페인은 총 30장이고 6장 단위의 다섯 지역으로 구성됩니다. 처음에는 1~6장만 보이며 6·12·18·24장의 마수 수비 성채를 함락할 때마다 다음 여섯 장이 지도에 추가됩니다. 지도 영역은 스크롤바뿐 아니라 마우스나 터치 드래그로 좌우 이동할 수 있습니다.
- 지도는 저장된 클리어 기록에 따라 점령 상태를 다시 그립니다. 각 지역의 6번째 보스 공성전을 끝내면 해당 지역이 해방 색과 왕국 깃발·봉화로 바뀌고, 정복한 거점 사이의 길만 금색 실선으로 복구됩니다. 현재 전선과 점령 경로는 서로 다른 점선 형태를 사용하며 미발견 마수 균열은 계속 숨겨집니다.
- 대륙은 서부 해안, 점령 왕도, 잿불 고원, 정령 설원, 마계 균열의 다섯 삽화형 지형 패널이 북쪽과 남쪽으로 굽이치며 이어지는 2D 세계로 표현됩니다. 지도는 마우스·펜 드래그와 터치·가로/세로 스크롤바로 상하좌우 이동하고, `지역 바로가기`로 열린 지역의 중앙에 이동할 수 있습니다. 전투 결과나 이탈 후에는 가장 멀리 해금한 장이 아니라 방금 전투한 캠페인·마수 도전·보물 수호전·파밍 거점 위치로 즉시 돌아와 화면 페이드와 긴 지도 스크롤이 겹치지 않습니다. 일반 점령 요새·보스 성채·해방 거점은 전투용 성채와 다른 지도 전용 원화를 사용합니다.
- 지도 빈 공간에는 해안 절벽·수림·호수·수로교·화산 봉우리·폭포·설원 숲·정령호·마계 첨탑 같은 비상호작용 랜드마크가 지역 해금에 맞춰 나타납니다. 12장 이후 `황금 수송로 탈환전`은 승리마다 기본 2,000골드를, 18장 이후 `왕립 대훈련장`은 전투 숙련 XP 2배를 제공합니다. 최종 30장을 마치면 스토리 이후 자유 원정인 `마왕군 잔당 대토벌`이 열려 30장보다 강한 적에게 승리할 때마다 기본 5,000골드를 줍니다. 세 전투는 캠페인 진행이나 보물 최초 보상을 갱신하지 않습니다. 지도 성채 표식은 투명 PNG를 사용해 해방된 보스 성채 주변에 사각 배경이 생기지 않습니다.
- 일곱 마수 균열은 투기장·월식·폭풍·룬·심연·태양·하늘 왕좌의 형태와 문양이 모두 다릅니다. 각 지역의 첫 일반 스테이지 1·7·13·19·25장을 클리어하면 스토리 보스와 무관한 장소에 매우 강한 보물 수호자가 나타납니다. 매복 교차사격, 수호·치유 진형, 지면 마법, 지상·공중 동시 압박, 삼중 지휘 방어선의 기믹 전투를 이기면 수호자 뒤에 짧은 길과 보물 상자가 열립니다. 상자를 직접 눌러 600·1,200·1,800·2,400·3,000금화를 한 번 수령하며, 사이드 전투는 캠페인 진행도를 올리지 않고 반복할 수 있습니다.
- 1~6장의 서부 변경 전투는 오프닝의 저채도 남색·풍화된 금색 미술 방향을 잇는 전용 20:9 폐허 배경을 사용합니다. 전투 판독성을 위해 하단 레인은 낮은 대비로 비워 두며, 아직 전용 원화가 없는 나머지 지역과 도전은 잘못된 지역 그림을 재사용하지 않고 기존 절차형 배경을 유지합니다.
- 지도 위 일반 임무는 성벽·탑·창문·아치형 성문을 갖춘 작은 적 성채로 표시되고, 마수 공성전은 더 크고 붉은 성채로 구분됩니다. 마수 도전 균열은 성채가 없는 별도 전투이므로 기존 균열 표식을 유지합니다.
- 지도 임무 패널의 `전투 평가`는 스테이지 번호가 아닙니다. 실제 성채 체력, 병력과 등장 시점, 지속 증원, 정예, 보스, 전장 거리를 분석해 `낮음·보통·높음·매우 높음·극한`의 5단계로 표시합니다.
- 전투의 아군 성채와 적 성채 사이는 1장부터 1,050 가상 거리만큼 떨어집니다. 스테이지마다 25씩 늘어나 15장에서 1,390 상한에 도달하고, 이후 스테이지는 같은 최대 거리를 유지합니다.
- 이후 스테이지 최초 클리어에서도 영웅, 추가 금화, 새로운 운영 기능처럼 정해진 보상을 한 번만 획득합니다. 9장에서는 왕실 교관단이 복귀해 영웅의 전당 내 숙련 기능이 해금되고, 12장에서는 성녀 미레나, 15장에서는 오크 족장 카루크, 18장에서는 해방군 기수 브란, 24장에서는 바람 정령 네리스를 획득합니다. 이미 해당 장을 깬 구버전 기록도 불러올 때 새 영웅 보상을 복구합니다.
- 왕국 지도에서 현지 날짜 기준 하루 한 번 `왕실 보석` 10개를 받을 수 있습니다. 현재 보석 충전이나 현금 결제는 없으며 출석과 업적 보상으로만 쌓입니다. 6장 첫 마수 공성전을 클리어하면 `수수께끼 상인`이 나타납니다. 상인은 보석 200개의 `전투 가속 허가`와 12·18·24장 이후 순서대로 구매하는 보석 150·250·350개의 편성 확장 허가를 판매합니다.
- 아군과 적군은 같은 52종 병종 데이터와 기본 능력치를 공유합니다. 왕국군·배신자·고블린·오크·오우거·마물과 야수·정령·악마의 여덟 세부 계열을 포괄하며 그리폰, 왕국 마법사, 대마법사, 이프리트, 창공의 고룡, 대륙연합 수호자도 각각 독립 병종입니다.
- 모든 병종에는 태생적 위상과 획득 난도를 나타내는 1~5성 고정 등급이 있습니다. 성급 자체는 능력치를 더하지 않으며 장비·숙련과 별개의 강화 단계도 아닙니다. 5성만 `초월`로 분류되고, 그리폰은 4성, 미노타우로스는 3성입니다. 획득하거나 정체를 확인한 병종의 등급은 병영·전쟁 사전·전투 카드에서 확인할 수 있습니다.
- 52종의 모든 병종과 인간·오크·정령으로 구성된 7명의 모든 영웅은 일곱 개의 오리지널 투명 캐릭터 아틀라스에 각자의 전용 원화를 갖습니다. 적군은 아군과 동일한 원본을 반전해 사용하며, `yarn art:atlas`는 보관된 RGBA 원본에서 코어를 포함한 일곱 런타임 아틀라스를 결정적으로 재생성합니다. 5성 초월 병종은 전투에서 일반 캐릭터 원화의 1.9배 크기로 표시되지만 충돌·사거리·배치 간격은 바뀌지 않습니다.

- 성채 기술은 `지휘·보급`, `성장 지원`, `성벽 공학`, `왕실 포병`, `원정 전술`의 5개 구현 트리와 총 28개 노드로 구성되며, 각 노드는 5단계까지 연구할 수 있습니다. 선행 관계와 갈래가 연결선으로 표시되는 가로 기술 트리이며 깊은 구간은 마우스·터치 드래그, 트랙패드, 스크롤바로 이동할 수 있습니다. 누적 연구 8회와 24회에 금화를 지불해 2·3티어로 승급합니다. 성벽 공학에는 2티어 `심층 기초 보강`과 3티어 `불락의 성벽핵`이 추가되어, 방어 연구를 모두 마치면 단계·승전 기념비 보너스 전 기준 체력 25,550·피해 감소 75·재생 50 HP/초의 버티기 전략을 구성할 수 있습니다. 30장 단계 보정까지 포함하면 27,580 HP, 다섯 기념비 완성까지 포함하면 31,580 HP입니다. 두 신규 노드 완성에는 각각 6,000·12,000골드가 필요합니다. 성장 지원 트리에서는 2티어 `전리품 회계`와 `왕립 야전 교범`으로 전투 골드와 전투 숙련 XP를 단계마다 5% 올리고, 전리품 회계 2단계 뒤의 `전리품 탐색대`로 승리 아이템 드롭률을 단계마다 4%p 올릴 수 있습니다. 일반 적 처치는 지휘력 3을 회복하며 `승전 공납제`는 단계마다 +0.5, 최대 5.5까지 올립니다. 원정 전술은 집결 깃발, 영웅 스킬·부활 시간, 전시 동원령을 강화하며 이프리트와 고룡 같은 5성 초월 병종의 지휘는 최종 연구가 필요합니다.
- 2티어는 고블린 약탈병·오크 철갑병과 돌격 특화 왕립 기마병, 3티어는 석궁병과 공중 병종 그리폰 기수 영입을 허가합니다. 오우거 파쇄자·다이어울프·폭풍 정령·룬 골렘·마염견·이프리트·창공의 고룡은 성채 티어나 금화가 아니라 해당 마수 도전의 최초 격파로만 합류합니다. 나머지 확장 병종은 13~29장에서 순차 조우한 뒤 병영에서 영입합니다.
- 전쟁 사전에는 획득하거나 실제 전투에서 조우한 병종, 획득한 영웅, 조우한 보스만 기록됩니다. 양 진영에서 본 같은 병종은 한 항목으로 계산되며 50%, 100% 완성 업적이 있습니다.
- 모든 UI 글자는 최소 10px이며, 좁은 화면에서도 헤더의 제목·언어 선택·재화와 편성 이름·전투 카드·훈련 설명이 겹치지 않도록 줄바꿈과 스크롤 배치를 사용합니다. 페이지 헤더의 게임명과 화면 제목은 선택한 언어로 표시합니다.
- 한국어 UI에서는 지도·병영·영웅·성채·업적·사전·결과 화면의 섹션명과 상태 문구를 한국어로 통일합니다. 영어·일본어 선택 시 같은 한국어 원문 키가 해당 언어로 바뀌며, 영문 표기는 게임 로고·단축키·나침반·통용 능력치 약어와 기술 크레딧에만 남습니다.
- 업적 기록 화면은 킬, 병사 및 영웅 사망, 승패, 연승, 보스 승리, 소환, 스킬 사용과 사전 완성도를 누적하며 금화와 왕실 보석 보상을 함께 제공합니다. 기본 `묶음 보기`는 64개 업적을 같은 통계의 12개 단계형 카드로 합치고 받을 보상과 다음 목표를 우선 표시합니다. `전체 보기`로 전환하면 모든 단계가 펼쳐집니다. 처치는 최대 5,000명, 승리와 참전은 250회, 소환은 2,500회, 영웅 스킬과 포격은 500회까지 장기 목표가 이어집니다.

- 영웅 각성 능력은 각성 후에만 공개되며, 현재 도달한 각성 단계의 효과만 표시합니다.

- 원정 장비고에는 보유 아이템과 지금 조합 가능한 항목만 표시됩니다. 전체 아이템 효과·획득 방법·조합법은 `전쟁 사전 → 아이템 사전`에서 확인합니다.

## 기술 구성

- React: 메뉴, 왕국 지도, 병영, 영웅의 전당, 전쟁 사전, 전투 HUD
- Phaser 4.2.1 WebGL: 전투 시뮬레이션과 렌더링
- Web Audio API: 외부 음원 없이 생성되는 메뉴·전투·결과 BGM과 전투 효과음
- Zustand: 병종 영입과 편성, 장비, 숙련 경험치, 성채 기술, 업적 통계, 전투 가속 권리와 선호 속도, 3슬롯 localStorage 자동 저장과 암호화 JSON 임포트·익스포트
- 자체 i18n 계층: 한국어 원문 키, 지연 로드되는 영어·일본어 메시지, React 화면 트리 번역, Phaser 런타임 문구 번역, 브라우저 언어 감지와 저장 슬롯 외부의 전역 언어 설정
- Web Crypto API: AES-256-GCM 저장 암호화와 인증, PBKDF2-SHA-256 키 유도, SHA-256 파일 체크섬
- Vitest: 전투 규칙 단위 테스트와 빌드에서 분리된 캠페인 난이도·병종 지휘 효율 분석

프로덕션 빌드는 초기 앱, React/Zustand, 지연 로딩되는 전투 UI, Phaser 4 런타임을 별도 청크로 출력해 메인 메뉴 진입 시 Phaser를 내려받지 않습니다. Phaser 4 전환 후 전용 청크는 약 1,375KB, gzip 약 357KB이며 기존 Phaser 3.90 대비 gzip 약 39KB 증가했습니다.

개발 도구는 Yarn Classic, Vite 8, TypeScript 7.0.2, Oxlint를 사용합니다. TypeScript 8은 2026-09-12 기준 공식 패키지가 아직 없어 최신 안정판인 7.0.2를 사용합니다. Pretendard Variable은 패키지로 설치하지 않고 런타임 CDN에서 불러옵니다. AI 에이전트 작업 규칙, 게임 명세, 모듈 참조 지도, 수치 밸런스 기준은 각각 `AGENTS.md`, `docs/GAME_SPEC.md`, `docs/ARCHITECTURE.md`, `docs/BALANCE.md`에 있습니다.

한국어 모드는 제목·로고·영문 표기·숫자·단축키까지 Pretendard를 사용합니다. 영어·일본어 모드는 기존 표시용 글꼴 구성을 유지하며, 언어를 바꾸면 글꼴도 즉시 전환됩니다. 전투 캔버스 글자는 필요한 Pretendard 글리프를 불러온 뒤 다시 그립니다.

스타일은 `src/main.tsx`에서 `base → components → menu → map → armory → progression → battle → responsive` 순서로 불러옵니다. 화면별 수정은 해당 맥락 CSS에서 하고, 공통 컴포넌트는 `components.css`, 모바일·가독성 덮어쓰기는 마지막 `responsive.css`에 둡니다.

아직 구현되지 않은 차기 시스템과 완료 조건은 `docs/FUTURE_SYSTEMS.md`에 `Planned`/`Partial` 상태로 관리합니다. 탱커의 관통 차단·후방 파동 감쇠와 이를 우회하는 지면 발현 마법은 구현을 마쳐 현재 전투 명세로 이동했습니다.

`yarn balance`는 앱 빌드와 별도로 실제 병종·웨이브·증원·정예·성채 내구도와 수비 사격·보스 데이터를 읽어 30개 캠페인 스테이지의 추정 난이도가 역전 없이 거의 선형으로 증가하는지 검사합니다. 동시에 모든 병종의 배치 위협도/지휘력 효율을 검증하고, 시작 골드와 최초 클리어 보상을 한 병종의 한 장비에 전부 투자하는 집중 강화 시나리오를 출력합니다. 민병대 무기 +5를 4장 전에 완성하는 극단적 빌드도 초기 상대 난이도 상승 폭이 ×0.95~×1.35 안에 머물고, 4장은 최소 ×1.05 상승하도록 검사합니다. 밸런스 변경 시 일반 테스트와 함께 실행해야 합니다.

전투 배경·효과는 Phaser 도형으로 구성되며, 양 진영 성채와 병사·영웅은 프로젝트에 포함된 오리지널 투명 PNG 원화를 사용합니다. 단일 자세 캐릭터는 분리된 가짜 팔을 덧그리지 않고 원화 자체의 짧은 이동·회전으로 공격을 표현합니다. 오프닝은 네 장의 오리지널 시네마틱 WebP 원화를 사용합니다. 성채·캐릭터·오프닝의 원본과 생성 기록은 각각 `public/assets/fortresses/`, `public/assets/characters/`, `public/assets/opening/`에 보관합니다.

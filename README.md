# Last Bastion — 최후의 성채

마왕군에게 대륙 전체를 빼앗기기 직전, 최후의 성채에서 반격을 시작하는 웹 기반 횡스크롤 공성 게임입니다. 왕국군은 배신한 인간군과 고블린·오크·오우거 같은 몬스터, 속박된 정령, 악마 군세를 차례로 돌파해 마왕성으로 진격합니다.

## 실행 방법

```bash
yarn install
yarn dev
```

프로덕션 빌드와 테스트:

```bash
yarn test
yarn balance
yarn lint
yarn build
yarn art:atlas
```

## 플레이 방법

- 타이틀 화면에는 서로 독립적인 저장 슬롯 3개가 있습니다. 빈 슬롯은 `새 게임`, 사용 중인 슬롯은 `이어하기 · 내보내기 · 삭제`를 표시합니다. 새 게임은 선택한 슬롯만 초기화하고 전용 16:9 원화·문구 페이드·카메라 움직임·진행 바로 구성된 약 21초의 네 장면 반격 시네마틱을 자동 재생한 뒤 왕국 지도로 이어집니다. 다음 버튼은 없으며 `오프닝 건너뛰기`나 Esc로 즉시 넘어갈 수 있습니다.
- `내보내기`는 8자 이상의 사용자 비밀번호로 저장 파일을 AES-256-GCM 암호화합니다. PBKDF2-SHA-256 210,000회, 저장마다 새 salt·IV, Base64 인코딩, SHA-256 체크섬을 사용하며 비밀번호는 저장하지 않습니다. `암호화 저장 가져오기`는 복호화·체크섬·인증 검증 뒤 대상 슬롯을 선택하고, 사용 중인 슬롯은 별도 덮어쓰기 확인을 거칩니다. 게임 버전과 저장 스키마 버전도 파일에 함께 기록됩니다.
- 기존 `last-bastion-profile-v1` 단일 자동 저장은 업데이트 후 슬롯 1로 한 번 자동 이전됩니다. 과거 평문 휴대용 JSON, 원본 상태 JSON, Zustand `{ state, version }` 래퍼도 계속 가져올 수 있지만 새로 내보내는 파일은 암호화 형식만 사용합니다.
- 새 게임, 저장 가져오기 덮어쓰기, 전체 진행 초기화처럼 되돌리기 어려운 작업은 브라우저 시스템 경고 대신 게임 스타일 모달로 확인합니다. 모달은 Esc 닫기, 안전한 버튼 우선 포커스, Tab 포커스 순환을 지원합니다.
- 병영과 강화, 영웅의 전당, 성채 기술, 업적 기록, 전쟁 사전, 출석 보상, 수수께끼 상인, 사운드 설정은 왕국 지도의 `왕국 운영` 패널에서 이용합니다. 데스크톱에서는 지도 바깥 왼쪽의 작은 세로 패널, 좁은 화면에서는 지도 위의 압축 도구막대로 표시되며 각 관리 화면과 전투 결과에서 뒤로 가면 왕국 지도로 복귀합니다.
- 신규 기록은 민병대 하나로 시작합니다. 왕국 지도 1~3장을 최초 클리어하면 방패병, 궁수, 창병을 순서대로 획득합니다.
- 캠페인은 총 30장이고 6장 단위의 다섯 지역으로 구성됩니다. 처음에는 1~6장만 보이며 6·12·18·24장의 마수 수비 성채를 함락할 때마다 다음 여섯 장이 지도에 추가됩니다. 지도 영역은 스크롤바뿐 아니라 마우스나 터치 드래그로 좌우 이동할 수 있습니다.
- 지도 위 일반 임무는 성벽·탑·창문·아치형 성문을 갖춘 작은 적 성채로 표시되고, 마수 공성전은 더 크고 붉은 성채로 구분됩니다. 마수 도전 균열은 성채가 없는 별도 전투이므로 기존 균열 표식을 유지합니다.
- 지도 임무 패널의 `전투 평가`는 스테이지 번호가 아닙니다. 실제 성채 체력, 병력과 등장 시점, 지속 증원, 정예, 보스, 전장 거리를 분석해 `낮음·보통·높음·매우 높음·극한`의 5단계로 표시합니다.
- 전투의 아군 성채와 적 성채 사이는 1장부터 1,050 가상 거리만큼 떨어집니다. 스테이지마다 25씩 늘어나 15장에서 1,390 상한에 도달하고, 이후 스테이지는 같은 최대 거리를 유지합니다.
- 이후 스테이지 최초 클리어에서도 영웅, 추가 금화, 새로운 운영 기능처럼 정해진 보상을 한 번만 획득합니다. 9장에서는 `영웅 훈련소`, 12장에서는 성녀 미레나, 15장에서는 오크 족장 카루크, 18장에서는 해방군 기수 브란, 24장에서는 바람 정령 네리스를 획득합니다. 이미 해당 장을 깬 구버전 기록도 불러올 때 새 영웅 보상을 복구합니다.
- 왕국 지도에서 현지 날짜 기준 하루 한 번 `왕실 보석` 10개를 받을 수 있습니다. 현재 보석 충전이나 현금 결제는 없으며 출석과 업적 보상으로만 쌓입니다. 6장 첫 마수 공성전을 클리어하면 `수수께끼 상인`이 나타납니다. 상인은 보석 200개의 `전투 가속 허가`와 12·18·24장 이후 순서대로 구매하는 보석 150·250·350개의 편성 확장 허가를 판매합니다.
- 아군과 적군은 같은 51종 병종 데이터와 기본 능력치를 공유합니다. 왕국군·배신자·고블린·오크·오우거·마물과 야수·정령·악마의 여덟 계열을 포괄하며 그리폰, 왕국 마법사, 대마법사, 이프리트, 창공의 고룡도 각각 독립 병종입니다.
- 모든 병종에는 태생적 위상과 획득 난도를 나타내는 1~5성 고정 등급이 있습니다. 성급 자체는 능력치를 더하지 않으며 장비·숙련과 별개의 강화 단계도 아닙니다. 5성만 `초월`로 분류되고, 그리폰은 4성, 미노타우로스는 3성입니다. 획득하거나 정체를 확인한 병종의 등급은 병영·전쟁 사전·전투 카드에서 확인할 수 있습니다.
- 51종의 모든 병종과 인간·오크·정령으로 구성된 7명의 모든 영웅은 일곱 개의 오리지널 투명 캐릭터 아틀라스에 각자의 전용 원화를 갖습니다. 적군은 아군과 동일한 원본을 반전해 사용하며, `yarn art:atlas`는 보관된 RGBA 원본에서 여섯 개의 비핵심 아틀라스를 결정적으로 재생성합니다. 5성 초월 병종은 전투에서 일반 캐릭터 원화의 1.9배 크기로 표시되지만 충돌·사거리·배치 간격은 바뀌지 않습니다.
- 병영에는 계열별 필터가 있으며 전체 51종을 한꺼번에 탐색하거나 왕국군·고블린·정령·악마 등 원하는 계열만 볼 수 있습니다.
- 병영에서 보유 병종 중 기본 4종을 전투 편성합니다. 세 번의 편성 확장 허가를 순차 구매하면 최대 7종까지 편성하며, 전투 하단 카드나 편성 순서에 해당하는 숫자키 `1`~`7`로 병사를 소환합니다. 병영 상단의 현재 편성 칩을 누르면 다른 계열 필터를 보고 있어도 해당 병종을 바로 제외할 수 있습니다. 소환 후 카드의 어두운 오버레이가 애니메이션으로 걷히며, 준비되는 순간 카드가 짧게 점등됩니다.
- `Q`로 영웅 스킬을 사용합니다. 영웅 초상화에도 `Q`가 표시되며, 기존 `Space` 입력도 보조 단축키로 사용할 수 있습니다. `E` 또는 동원 버튼으로 지휘력 300·400·500을 순서대로 소비하면 그 전투의 최대 지휘력이 매번 100씩 오르며, 전투당 최대 3회 발동합니다. 원정 전술의 `동원 전술 훈련`은 발동마다 단계당 초당 회복 +0.3을 추가합니다. `집결 신호`를 연구하면 `R`로 위치 지정 모드를 열고 전장 클릭으로 깃발을 세웁니다. 1~4성 병사부터 시작해 후속 연구로 영웅과 5성 초월 병종까지 그 위치로 모아 전선을 전진·후퇴시킬 수 있습니다. 집결은 전투 시간 기준 12초 뒤 자동 해제되며 HUD에 남은 시간이 표시되고, × 버튼으로 더 일찍 자동 진군을 복구할 수도 있습니다. 위치 지정 중 Esc는 취소하고, 평상시 `P` 또는 `Esc`는 일시정지합니다.
- 전투 가속 허가를 구매하면 전투 HUD의 속도 버튼으로 `1× / 1.5×`를 전환할 수 있습니다. 이동, 공격, 소환, 지휘력 회복, 재사용 대기시간, 영웅 부활, 보스 패턴과 전투 시간이 같은 배율로 진행되며 마지막 선택은 자동 저장됩니다.
- 메뉴·전투·승리·패배에는 서로 다른 오리지널 절차형 BGM이 재생되며 근접 타격, 사격, 공중 공격, 포격, 성채 피격, 영웅 스킬 효과음이 함께 재생됩니다. 브라우저 정책상 첫 클릭이나 키 입력 이후 시작하며, 왕국 지도의 사운드 메뉴와 전투 HUD 버튼으로 모든 게임 사운드를 켜고 끌 수 있습니다.
- 병사는 자동으로 이동하고 유효 사거리 안의 적을 공격합니다. 공격마다 서로 다른 선딜과 후딜이 있으며 두 구간에는 이동할 수 없습니다. 선딜이 끝날 때 목표가 죽거나 사거리·성채 엄폐 밖으로 벗어나면 빗나갑니다. 장거리 병종은 가까운 적을 맞히지 못하는 사각이 있어 전열이 파고들면 뒤로 물러납니다. 전용 투명 원화 뒤에는 예전 절차형 캐릭터용 기하학 배경을 겹치지 않으며, 공격할 때 캐릭터 전체가 찌그러지지 않고 원화와 체력바는 고정된 채 병종에 맞는 팔·무기·활·마법·돌진 레이어가 선딜에 맞춰 움직입니다.
- 아군 병사와 영웅은 성채 뒤에서 출전하거나 부활합니다. 성채가 살아 있는 동안 뒤쪽 병력은 적의 직접 표적이 되지 않으므로 원거리병은 성채를 방패 삼아 사격할 수 있고, 근거리병은 성채 선을 통과해 반격합니다. 적군 병력에도 같은 규칙이 적용되며 적 성채를 파괴하면 뒤의 수비병이 노출됩니다.
- 민병대·약탈병은 한 번에 3명, 방패병·궁수는 한 번에 2명이 소환됩니다. 지휘력과 재사용 대기시간은 카드 사용 한 번에 지불합니다. 궁수는 사거리와 반응 속도가 좋고 2명이 한 대상을 집중 공격하며, 석궁병은 사거리와 최소 사거리가 불리하고 장전 선딜도 길지만 한 발이 강하고 일렬로 선 최대 2명을 관통합니다. 방패병·철갑병·일부 중장 병종과 에드릭은 자신에게 닿은 관통을 끊고 뒤쪽 지상 병력까지 이어지는 전방 파동의 남은 사거리를 줄입니다. 반대로 왕국 마법사·오크 주술사·오우거 마도사·심연 마도사의 지면 발현 마법은 가장 밀집한 위치를 먼저 경고한 뒤 바닥에서 솟아 탱커의 직선 보호를 우회하며, 경고 중 범위 밖으로 피할 수 있고 공중 병종은 맞지 않습니다. 대마법사의 전방 파동은 지상과 공중을 모두 공격하지만 지상 수호병 뒤에서는 짧아집니다. 공격 방식·유효 사거리·수호 특성은 병영과 전쟁 사전에서 확인하지만, 정확한 선딜/후딜은 직접 운용해 숙련 5레벨에 도달한 뒤 전쟁 사전에서 분석됩니다.
- 전장 사제는 치유 범위 안에서 가장 크게 다친 아군을 우선 회복하며 부상자가 없을 때만 적을 공격합니다. 같은 병종 데이터를 쓰는 적 사제도 동일하게 적 전열을 치유합니다.
- 신수·마수급 소환수와 일부 거대 병종은 한 진영이 전장에 동시에 유지할 수 있는 수가 2명 또는 3명으로 제한됩니다. 이 제한은 아군과 적군에 똑같이 적용되고, 배치 인원 완성 보너스를 받는 병종도 남은 자리만 출전합니다. 병영은 진영당 제한을, 전투 카드는 현재 인원과 상한을 표시합니다.
- 영웅 초상화를 누르거나 `Q`를 눌러 선택한 영웅 고유 스킬을 사용합니다.
- 영웅의 전당에서 다섯 인간 영웅과 오크 족장 카루크, 공중형 바람 정령 네리스를 해금·선택·강화할 수 있습니다. 카루크는 근접 광역 피해와 아군 보호막을 함께 제공하고, 네리스는 지상·공중·성채를 휩쓰는 전방 폭풍을 사용합니다.
- 모든 영웅은 지휘력을 소비하지 않으며 쓰러지면 각자의 부활 시간이 지난 뒤 성채 앞에 돌아옵니다.
- 성채 포격 버튼으로 성채 기준 최대 사거리 안에 들어온 가장 가까운 지상 적 전열에 범위 피해를 줄 수 있습니다. 화살·마법·폭탄·성채탄은 전장에서 서로 다른 투사체로 표현됩니다.
- 일반 스테이지는 적 성채를 파괴하면 승리합니다.
- 후반 스테이지의 적은 별도 복제 병종이 아니라 같은 병종에 무기·갑옷·장화 강화를 적용합니다. 컴퓨터 병력과 보스에는 숙련도가 없으며, 세 장비 모두 5단계 상한이 있습니다. 정확한 적 장비 단계와 정예 보정 수치는 지도에서 숨겨 전투 전 스포일러를 줄입니다. 13장부터는 적 성채도 전방의 아군을 기본 사격하며, 지도 임무 패널에서 공격력·사거리·간격을 미리 확인할 수 있습니다. 성채를 파괴하면 사격과 증원이 모두 멈춥니다.
- 2~11장의 일부 일반전에는 적 성채 앞 정예 수비대가 한 명 배치됩니다. 13~17장 일반전은 전선 55%와 86% 지점에 두 명, 19~29장 일반전은 38%·64%·87% 지점에 세 명의 이름 있는 중간 우두머리를 배치합니다. 모두 그 지역에서 조우한 1~3성 병종과 장비 데이터를 재사용하는 단일 개체이며, 지도에는 이름과 수만 보이고 체력·공격·방어 보정은 숨깁니다. 캠페인 보스 공성전에는 별도의 중간 우두머리를 추가하지 않습니다.
- 일반 스테이지의 적은 초반 웨이브가 끝난 뒤에도 병종을 순환하며 계속 증원합니다. 전장의 적이 너무 많으면 생산을 잠시 늦추고, 적이 줄면 다시 보충합니다.
- 상위 병종은 단계적으로 등장합니다. 보스 직후 7장은 기존 병종을 복습하는 완충 구간이며, 8장 중반에 기마병, 10장 후반에 그리폰이 한 기만 처음 등장합니다. 13~29장의 일반 전투는 두 번째 웨이브부터 해당 지역의 몬스터·정령·악마를 기본 병사 사이에 교차 배치하고, 이미 조우한 1~3성 지역 병종도 위력에 맞춘 느린 간격으로 계속 증원합니다. 4성 전설은 유한 웨이브로만 등장해 무한히 쌓이지 않습니다. 모든 4성 전설·5성 초월 병종은 장비 전에도 기본 체력이 1,000 이상이며, 그리폰은 200 지휘력·체력 1,600·공격력 150의 공중 강습병입니다. 기본 체력 11,000의 이프리트와 체력 15,000의 창공의 고룡은 캠페인 일반 웨이브에 등장하지 않고 30장 완료 후 각자의 도전에서 처음 조우합니다. 강한 병종은 제한된 웨이브와 동시 배치 상한으로 조절되며, 고룡은 진영당 한 마리만 생존할 수 있습니다.
- 캠페인 6·12·18·24·30장은 서로 다른 마수와 적 성채가 함께 등장하는 보스 공성전입니다. 성채는 하위 병종으로 구성된 소규모 수비대를 느리게 계속 보충하며, 성채를 먼저 파괴하면 증원이 멈춥니다. 마수와 성채를 모두 파괴해야 승리합니다. 마수는 첫 공격을 받으면 달려들고, 체력 55%부터 공격·이동·내려찍기 속도가 크게 상승합니다.
- 마수 도전은 별도 메뉴가 아닙니다. 6·12·18·24·27·30장을 클리어할 때마다 확장된 대륙 지도에 붉은 `마수 균열`이 나타나며, 해당 노드를 찾아 직접 선택합니다. 6~27장에는 오우거 파쇄자·다이어울프·폭풍 정령·룬 골렘·마염견을 보상으로 주는 2~4성 도전이 차례로 열리고, 30장에는 5성 초월 병종인 이프리트와 창공의 고룡 도전이 열립니다. 적 성채나 지원군 없이 우두머리 하나만 상대하고, 적은 고유 지형에서 체력 10배·공격력 2.5배 보정을 받습니다. 최초 격파 시 지형 보정이 제거된 같은 기본 병종을 영입합니다.
- 전투에서 얻은 금화로 각 병사와 영웅의 무기·갑옷·장화를 각각 최대 5회 강화할 수 있습니다. 장비는 병종 역할에 맞춘 고정 공격력·체력·방어력·이동속도를 올립니다. 장비 하나를 5단계까지 완성하면 일반·3성·인간형 4성 병종은 1회 배치 인원이 1명 늘어납니다. 5성과 `large` 4성 거대 병종은 1명을 유지하는 대신 모든 장비 효과 3단계분의 고정 능력치를 추가로 받습니다. 늪지 히드라는 완성 보너스로 HP +630, 공격 +36, 방어 +4.5, 이동 +3을 받으며 어느 완성 보너스도 중첩되지 않습니다.
- 장비와 성채 연구 비용은 `기본값 × 다음 단계`의 읽기 쉬운 수열을 사용합니다. 병종 장비 기본가는 1성 50·75, 2성 100, 3성 200, 4성 300, 5성 400금화입니다. 스테이지 승리 보상은 1장 100금화부터 30장 3,000금화까지 100씩 증가합니다.
- 병사와 영웅 카드의 생명력·공격력·방어력·이동속도 옆에는 장비와 숙련을 합산한 기본 능력치 대비 상승량이 표시됩니다. 숙련의 레벨당 고정 상승량도 카드에서 확인할 수 있습니다.
- 병사 소환과 영웅 출전은 별도의 숙련 경험치를 주며, 금화를 쓰지 않아도 숙련 레벨과 능력치가 계속 성장합니다. 병사는 최대 50레벨까지 역할별 고정 HP·공격력을 얻습니다. 영웅은 최대 30레벨까지 더 큰 고정 능력치와 함께 액티브 스킬 위력이 오르고 부활 시간이 줄며, 10·20·30레벨 각성마다 스킬 강화·재사용 대기시간 1.5초 단축과 함께 영웅별 범위 오라가 해금·강화됩니다.
- 15장에서는 마왕군에 등을 돌린 오크 족장 카루크가, 24장에서는 속박에서 풀려난 바람 정령 네리스가 합류합니다. 두 영웅도 전용 장비·숙련·각성·오라·액티브 스킬과 전쟁 사전 기록을 갖습니다.
- 9장 최초 클리어로 해금되는 영웅 훈련소에는 `250골드 → 100 XP`, `1,000골드 → 500 XP`, `2,500골드 → 1,500 XP` 훈련이 있습니다. 보유 영웅은 전용 원화와 현재 각성 단계가 표시된 초상 카드로 구분되며, 30레벨에 도달하면 더 이상 금화를 소비하지 않습니다.
- 30장 최초 클리어 뒤에는 `승전 기념비`가 열립니다. 최대 20단계까지 남는 골드를 투자해 단계마다 아군 병사·영웅의 체력·공격·치유를 1%, 아군 성채 체력을 150 올릴 수 있으며 적과 챌린지 지형 보정에는 적용되지 않습니다.
- 성채 기술은 `지휘·보급`, `성장 지원`, `성벽 공학`, `왕실 포병`, `원정 전술`의 5개 구현 트리와 총 23개 노드로 구성되며, 각 노드는 5단계까지 연구할 수 있습니다. 선행 관계와 갈래가 연결선으로 표시되는 가로 기술 트리이며 깊은 구간은 마우스·터치 드래그, 트랙패드, 스크롤바로 이동할 수 있습니다. 누적 연구 8회와 24회에 금화를 지불해 2·3티어로 승급합니다. 성장 지원 트리에서는 2티어 `전리품 회계`와 `왕립 야전 교범`을 각각 독립적으로 시작해 전투 골드와 전투 숙련 XP를 단계마다 5% 올릴 수 있습니다. `승전 공납제`는 단계마다 처치 지휘력 +1, `재생 석재`는 단계마다 성채 재생 +4 HP/초를 제공합니다. 원정 전술은 집결 깃발, 영웅 스킬·부활 시간, 전시 동원령을 강화하며 이프리트와 고룡 같은 5성 초월 병종의 지휘는 최종 연구가 필요합니다.
- 2티어는 고블린 약탈병·오크 철갑병과 돌격 특화 왕립 기마병, 3티어는 석궁병과 공중 병종 그리폰 기수 영입을 허가합니다. 오우거 파쇄자·다이어울프·폭풍 정령·룬 골렘·마염견·이프리트·창공의 고룡은 성채 티어나 금화가 아니라 해당 마수 도전의 최초 격파로만 합류합니다. 나머지 확장 병종은 13~29장에서 순차 조우한 뒤 병영에서 영입합니다.
- 전쟁 사전에는 획득하거나 실제 전투에서 조우한 병종, 획득한 영웅, 조우한 보스만 기록됩니다. 양 진영에서 본 같은 병종은 한 항목으로 계산되며 50%, 100% 완성 업적이 있습니다.
- 업적 기록 화면은 킬, 병사 및 영웅 사망, 승패, 연승, 보스 승리, 소환, 스킬 사용과 사전 완성도를 누적하며 금화와 왕실 보석 보상을 함께 제공합니다. 기본 `묶음 보기`는 64개 업적을 같은 통계의 12개 단계형 카드로 합치고 받을 보상과 다음 목표를 우선 표시합니다. `전체 보기`로 전환하면 모든 단계가 펼쳐집니다. 처치는 최대 5,000명, 승리와 참전은 250회, 소환은 2,500회, 영웅 스킬과 포격은 500회까지 장기 목표가 이어집니다.

## 기술 구성

- React: 메뉴, 왕국 지도, 병영, 영웅의 전당, 전쟁 사전, 전투 HUD
- Phaser 3: 전투 시뮬레이션과 렌더링
- Web Audio API: 외부 음원 없이 생성되는 메뉴·전투·결과 BGM과 전투 효과음
- Zustand: 병종 영입과 편성, 장비, 숙련 경험치, 성채 기술, 업적 통계, 전투 가속 권리와 선호 속도, 3슬롯 localStorage 자동 저장과 암호화 JSON 임포트·익스포트
- Web Crypto API: AES-256-GCM 저장 암호화와 인증, PBKDF2-SHA-256 키 유도, SHA-256 파일 체크섬
- Vitest: 전투 규칙 단위 테스트와 빌드에서 분리된 캠페인 난이도·병종 지휘 효율 분석

프로덕션 빌드는 초기 앱, React/Zustand, 지연 로딩되는 전투 UI, Phaser 런타임을 별도 청크로 출력해 메인 메뉴 진입 시 Phaser를 내려받지 않습니다.

개발 도구는 Yarn Classic, Vite 8, TypeScript 7.0.2, Oxlint를 사용합니다. TypeScript 8은 2026-09-12 기준 공식 패키지가 아직 없어 최신 안정판인 7.0.2를 사용합니다. Pretendard Variable은 패키지로 설치하지 않고 런타임 CDN에서 불러옵니다. AI 에이전트 작업 규칙, 게임 명세, 수치 밸런스 기준은 각각 `AGENTS.md`, `docs/GAME_SPEC.md`, `docs/BALANCE.md`에 있습니다.

아직 구현되지 않은 차기 시스템과 완료 조건은 `docs/FUTURE_SYSTEMS.md`에 `Planned`/`Partial` 상태로 관리합니다. 탱커의 관통 차단·후방 파동 감쇠와 이를 우회하는 지면 발현 마법은 구현을 마쳐 현재 전투 명세로 이동했습니다.

`yarn balance`는 앱 빌드와 별도로 실제 병종·웨이브·증원·정예·성채 내구도와 수비 사격·보스 데이터를 읽어 30개 캠페인 스테이지의 추정 난이도가 역전 없이 거의 선형으로 증가하는지 검사합니다. 동시에 모든 병종의 배치 위협도/지휘력 효율을 검증하고, 시작 골드와 최초 클리어 보상을 한 병종의 한 장비에 전부 투자하는 집중 강화 시나리오를 출력합니다. 민병대 무기 +5를 4장 전에 완성하는 극단적 빌드도 초기 상대 난이도 상승 폭이 ×0.95~×1.35 안에 머물고, 4장은 최소 ×1.05 상승하도록 검사합니다. 밸런스 변경 시 일반 테스트와 함께 실행해야 합니다.

전투 배경·효과는 Phaser 도형으로 구성되며, 양 진영 성채와 병사·영웅은 프로젝트에 포함된 오리지널 투명 PNG 원화를 사용합니다. 전투에서는 단일 자세 캐릭터 그림 위에 재사용 가능한 국소 공격 리그를 합성합니다. 오프닝은 네 장의 오리지널 시네마틱 WebP 원화를 사용합니다. 성채·캐릭터·오프닝의 원본과 생성 기록은 각각 `public/assets/fortresses/`, `public/assets/characters/`, `public/assets/opening/`에 보관합니다.

## 1. 총평

현재 게임은 51종 병종, 7명 영웅, 30개 캠페인, 7개 도전과 장비·숙련·성채 성장으로 수집하고 강화할 재료가 풍부하다. 대공·수호·관통·지면 마법의 전술 차이도 이미 있다. 새 병종 수를 먼저 늘릴 필요는 낮다.

가장 큰 개선 기회는 지역·보스·성장의 차이를 **화면, 동작, 전투 상황, 보상 순간으로 체감하게 하는 것**이다.

1. **다른 지역에 도착했다는 느낌:** 다섯 지역에 대응하는 전장 배경·성채·환경 연출.
2. **군대가 실제로 싸우는 느낌:** 단일 포즈 이동을 넘어서는 보행·사격·타격·사망 동작.
3. **기억나는 적과 전투:** 공통 마수 외형과 내려찍기에서 확장한 고유 실루엣·예고·대응법.
4. **병종을 바꿔 쓸 이유:** 추가 병종보다 역할 이해, 상황별 편성, 다양한 전술 문제.
5. **영토를 되찾는 보람:** 지도 해방, 영웅 합류, 숙련 각성, 성채 승급, 최종 승리의 특별한 순간.
6. **반복해도 지치지 않는 감각:** 음악 변주, 후반 전투 상황, 숫자 중심 보상의 연출 개선.

첫 제작 묶음은 **지역 배경 하나 + 대표 병종 동작 + 마수 하나의 전용 외형 + 타격 효과 + 보상 연출**을 한 전투 흐름에서 완성하는 것으로 잡는다. 모든 원화를 먼저 다시 만들거나 새로운 장기 시스템부터 붙이지 않는다.

## 4. 이미지·애니메이션·시청각

### GD-01 — 공통 미술 기준

Status: **Implemented**. 현재 기준은 [`ART_DIRECTION.md`](ART_DIRECTION.md)에 있으며 이후 자산 시범이 계약을 바꾸면 같은 변경에서 갱신한다.

- **현재/문제:** 오프닝은 넓은 공간과 극적인 조명, 캐릭터는 SD 전신, 전장은 도형 중심이다. 매체의 차이는 유지하되 같은 세계로 이어지는 기준이 필요하다.
- **방향:** 저채도 남색·풍화된 금색·국지적인 붉은 위협 색을 정리한다. 캐릭터/성채는 명확한 실루엣, 배경은 낮은 대비, 위험 경고는 가장 높은 정보 우선순위를 갖게 한다. 효과 색만으로 존재하지 않는 상태이상·속성 상성을 암시하지 않는다.
- **산출물:** `docs/ART_DIRECTION.md`에 팔레트, 윤곽·광원·시점·발 위치, 진영 표시, 효과 우선순위, 실제 표시 크기의 비교판. 기존 원화 유지/수정/신규 목록을 구분한다.
- **완료:** 오프닝→지도→전투에서 왕국 문장·재질·색이 연결된다. 확대 원화만으로 평가하지 않고 실제 작은 크기로 검수한다. 승인된 오프닝 자산은 보존한다.

### GD-02 — 지역별 배경과 환경

Status: **Partial**. `ruined-border` 시범만 구현되었고 나머지 지역·도전은 기존 절차형 폴백을 사용한다.

- **현재/문제:** 다섯 지역이 동일 전장 도형을 쓴다. 지역 진행이 적 조합과 설명문에 비해 시각적으로 덜 드러난다.
- **제안:** 하늘/원경/중경/지면을 분리한 환경 세트를 제작한다. 고정 카메라에 불필요한 카메라 이동을 추가하지 않으며 전경 장식은 전투를 가리지 않는다.

| 지역 | 랜드마크와 재질 | 환경 움직임 |
|---|---|---|
| 변경 | 불탄 농가, 무너진 벽, 먼 봉화 | 얇은 연기·풀·천 조각 |
| 왕도 | 훼손된 조각상, 점령 깃발, 석재 도로 | 늘어진 깃발·먼지 |
| 고원 | 화산 암석, 굴뚝, 잿빛 능선 | 드문 불씨·재 |
| 설원 | 얼어붙은 숲, 봉인석, 먼 오로라 | 약한 눈발·광점 |
| 균열 | 깨진 첨탑, 갈라진 하늘 | 느린 균열 맥동·상승 입자 |

- **도전:** 투기장/월식/폭풍/룬/심연/태양/하늘 왕좌는 지역 레이어를 재사용하면서 고유 중경과 환경 효과를 조합한다. 처음부터 대형 그림 7장 추가가 필수는 아니다.
- **경로/완료:** `src/data`의 배경 매핑을 `terrain.id`와 연결하고 `drawWorld()`가 소비한다. 제목 없이 대표 지역을 구분할 수 있다. 텍스처·레이어·입자 예산을 두고 모바일/1.5× 검수. **지형 능력치 변경 없음.**

### GD-03 — 성채 변형과 함락의 무게

- **현재/문제:** 양 진영에 각 한 성채 이미지가 있고 `drawCastle()`은 정적 이미지를 표시한다.
- **제안:** 왕도 수비군/오크 철장/정령 봉인/악마 성채의 문장·성문·지붕 변형. HP 감소는 연기·균열·깃발 손상으로, 함락은 성문 붕괴→먼지→깃발 소멸로 표현한다. 아군 티어에 따른 배너/증축도 검토한다.
- **산출물:** 정상/손상/파괴 레이어, `fortressArt.ts` 중앙 매핑 확장. 전체 성 재생성보다 재사용 레이어를 먼저 시범 제작한다.
- **완료:** 시각 변화는 충돌·배치·표적 X와 분리한다. 파괴 즉시 기존 규칙대로 엄폐·사격·증원이 끝나며 연출이 승패를 바꾸지 않는다. 보스 생존 중 함락을 승리처럼 표현하지 않는다. 도전에 성채를 추가하지 않는다.

### GD-04 — 병종·영웅의 작은 화면 식별성

- **현재/문제:** 궁수/리아는 녹색 후드와 활, 방패병/에드릭은 청색 갑옷과 방패가 비슷하다. 병력이 겹칠 때 구분이 유지되는지 확인해야 한다.
- **제안:** 무기·방패 모양, 영웅의 고유 망토·문장, 야수의 머리/날개, 정령 핵 모양을 구별한다. 색과 미세 장식만 늘리지 않는다.
- **추가 검수:** 원화 기록상 늑대·슬라임은 여러 개체를 한 프레임에 그린 경우가 있다. runtime은 living body마다 프레임을 그리므로 시각 개체 수와 HP/상한이 혼동되는지 검수하고 필요하면 단일 개체 원화를 만든다. squadSize는 변경하지 않는다.
- **완료:** 적군은 같은 canonical 원화, 진영은 별도 바닥/표식/HP바로 구분. 51종·7명 전용 프레임, 대형·5성 크기 계약 유지. 변경 자산만 versioning하고 `characterArt.ts`, atlas 빌더·원본 기록을 갱신한다.

### GD-05 — 실제 원화 기반 동작

- **현재/문제:** 단일 포즈 위 도형 리그는 보행, 날갯짓, 활 당김, 몸의 무게 이동에 한계가 있다.
- **1차 시범:** 민병대·방패병·궁수·그리폰·에드릭의 대기/이동/공격/피격/사망. 공격은 준비→타격→회수로 구분한다.
- **자산 계약:** 분리된 신체·무기 원본 또는 실제 다중 프레임 원화를 새로 만든다. PNG 확장자 변경이나 그림 전체 흔들기를 관절 애니메이션 완료로 보지 않는다. 기본 초상 atlas를 보존하고 애니메이션은 612×640/153×160 규격의 여러 시트로 확장하는 방안을 우선한다. 프레임·기준점·재생표는 중앙 아트 매핑에 둔다.
- **완료:** 발 미끄러짐, 중복 무기, 날개 크롭, 반전 오프셋을 검수한다. 기존 windup/impact/recovery와 동작을 맞추고 시각 프레임이 피해 판정 시계를 소유하지 않는다. HP바·그림자·컨테이너 전체를 공격마다 늘이거나 흔들지 않는다. 피격 동작에 새 경직을 몰래 추가하지 않는다. 사망 개체는 즉시 판정에서 빠지고 잔상만 제한적으로 유지한다.
- **확장:** 시범 품질·성능 확인 후 인간/기병/비행 야수/정령/거대체 묶음으로 확대한다. 원화 미제작 병종은 기존 국소 리그를 유지한다. 새로운 파이프라인이 기존 작업 계약을 바꾸면 AGENTS와 자산 문서도 함께 개정한다.

### GD-06 — 타격감과 효과의 의미

- **현재:** 화살/마법/폭탄/성채탄, 수호·지면 경고 풀이 이미 있다. 이를 폐기하지 않고 의미를 정교화한다.
- **제안:** 베기=방향성 궤적, 찌르기=좁은 충격, 방패=전방 금속 불꽃, 큰 타격=낮은 먼지, 치유=위로 모이는 빛. 시전 위치·도착 위치·피해 적용 시점을 일치시킨다.
- **완료:** 위험 경고는 장식보다 우선해 보이고 보호/피해/치유는 형태로도 구별된다. 일반 공격마다 화면 흔들기·시간 정지를 넣지 않는다. 효과 겹침에도 전선과 경고를 읽을 수 있다. 신규 효과는 풀·빈도 제한을 가지며 장식 포화로 필수 경고가 없어지지 않게 최소 표현을 보장한다.
- **검수:** GD-19 소리와 같은 사건에 맞춘 전후 영상 비교. 판정과 어긋나는 ‘멋진 효과’는 완료가 아니다.

### GD-07 — 캠페인 마수 5종 전용 외형

- **현재/문제:** 캠페인 마수는 다른 이름에 공통 몸체·절차형 표현을 쓴다. 주요 적의 인상을 강화할 필요가 있다.
- **시각 방향:** 6장=뿌리·뿔의 낮고 넓은 몸, 12장=성문 같은 철갑 전면, 18장=용광로 흉부, 24장=빙정 뿔과 속박 흔적, 30장=왕관과 균열의 비대칭 실루엣. 기존 이름과 설정에 맞춘다.
- **산출물:** 5개 실루엣 초안→6장 완성 시범→나머지 확장. 대기/공격 예고/격분/사망 포즈. `characterArt.ts`를 확장해 보스 매핑도 중앙화한다.
- **완료:** 이름 없이 대표 실루엣을 구분한다. 1차 외형 작업은 동일 combat 데이터에 적용해 수치를 보존한다. 별도 보스 정체성으로 codex를 늘리면 조우 규칙·분모 기반 업적·구형 저장도 함께 설계한다. 외형 5종이 도감 5종 추가를 자동 의미하지 않는다.

### GD-10 — 영웅 스킬과 각성의 고유 연출

- **방향:** 에드릭=방패선, 셀레네=낙하지점과 운석, 리아=화살비, 미레나=치유 대상으로 흐르는 새벽빛, 브란=깃발과 보호막, 카루크=도끼 충격과 아군 보호, 네리스=지상·공중을 잇는 전방 바람.
- **산출물:** 영웅별 cast/impact/잔여 효과·전용 아이콘, 각성 I/II/III의 일관된 계층. 반복 컷인보다 전투 판독을 우선한다.
- **완료:** 기존 능력을 정확히 시각화하고 실제 없는 버프나 범위를 암시하지 않는다. 각성은 알아볼 수 있지만 경고를 가리지 않는다. 수식과 쿨다운은 그대로이며 모션 축소·음소거에서도 사용 성공과 대상이 분명하다.

### GD-18 — 지역·전황별 음악

- **현재/문제:** 장면별 짧은 패턴은 있으나 지역/보스 구분이 없다. 장시간 피로는 실제 청취가 필요하다.
- **제안:** 같은 왕국 주제를 지역별 리듬·음색으로 변주한다. 일반전→각성→격분→승리에 강약을 두고 반복적으로 곡 처음으로 돌아가는 전환을 피한다.
- **산출물/완료:** 기존 Web Audio 엔진의 패턴·레이어·전환표부터 확장한다. 청취에서 음량 급변·반복 피로·효과음 마스킹을 확인한다. 1.5×가 템포를 바꾸지 않고 숨김/음소거 계약 유지. 외부 음원/엔진 이전은 별도 소유권·용량 설계가 필요하다.

### GD-19 — 재질·사건별 효과음

- **현재/문제:** 여섯 합성 음형이 많은 사건을 대표한다.
- **제안:** 금속 차단, 목재·육체 타격, 활시위·석궁, 돌·거대 발구름, 화염·바람·치유, 성문 붕괴를 구별한다. 영입·연구·각성·해방에는 짧은 UI 음향을 준다.
- **완료:** 소리와 실제 사건이 대응하고 보스 경고/영웅 사용 성공이 공격 소리에 묻히지 않는다. 동시 발음 수·우선순위·빈도 제한과 master mute를 유지한다. 청취 전후 비교를 남기며 실제 듣지 않았다면 완료로 표시하지 않는다.

## 5. 콘텐츠·전술·이야기·성장

### GD-08 — 보스마다 다른 대응법

- **현재/문제:** 공통 각성·분노·내려찍기에 HP·공격·주기가 달라지는 구조다. 도전은 기본 병종이 다르지만 고유 패턴 학습을 더 만들 수 있다.
- **후보:** 철갑=긴 전방 강타 예고와 회수 구간, 서리=지정 위치 지면 파열, 심연=순서가 보이는 연속 경고. 늑대 도전=돌진 예고, 폭풍=지정 위치 번개, 룬=느린 광역 충격. 확정 수치가 아닌 시범 설계 후보다.
- **대응:** 소환 타이밍·비행 병종·회복/보호 스킬·연구된 집결 등 이미 접근 가능한 수단을 쓴다. 첫 보스에서 미획득 기능을 필수 해법으로 요구하거나 무적 대기만 늘리지 않는다.
- **완료:** 준비 신호/피격 영역/지상·공중/회피 수단/실패 비용을 패턴별 표로 정의하고 실전 대응을 확인한다. 캠페인 보스+성채, 도전 단독 보스의 승리 조건 유지. 죽음/이탈 시 예약 피해 제거.
- **계약:** `src/data` 패턴→순수 판정→Phaser 표현. generic 규칙은 양 진영 공용, encounter-only 능력은 영입 병종에 섞지 않는다. estimator·BALANCE를 갱신하고 기존 패턴 추가/교체의 위협 변화도 감사한다.

### GD-09 — 기억나는 후반 전투 상황

- **현재:** 지역 신규 병종과 정예선은 이미 있다. 실제 반복감을 관찰하며 전술 차이를 강화한다.
- **제안:** ‘수호 전열 뒤 치유 끊기’, ‘유한 공중 위협 처리하며 공성 유지’, ‘마법 예고에 맞춘 전열 재배치’ 같은 대표 상황을 지역마다 설계한다. 모든 장에 모든 위협을 함께 넣지 않는다.
- **산출물:** 30장 신규 위협/전술 질문/가능한 대응/복습 구간 표. 먼저 후반 일반전 2개만 수제로 다듬어 기존 구성과 비교한다.
- **완료:** 이전 전투와 다른 선택이 성립한다. 하나의 최적 조합만 강요하지 않는다. 성채 파괴 목표·지속 증원·서명 병종 시점·4~5성 유한 위협 계약 유지. 호위/생존 등 새 승리 조건은 별도 모드 설계 없이 섞지 않는다.

### GD-11 — 합류 서사와 반격의 마무리

- **현재/문제:** 오프닝은 반격을 약속하지만 결과는 공통 승리 문구다. 최종 적은 마왕성의 마수이므로 대륙 해방과 마왕의 위협이 어떻게 마무리되는지 연결할 필요가 있다.
- **제안:** 지역 진입/지역 승리/카루크·네리스 합류에 짧은 대사나 그림·회고를 둔다. 적 병종 영입은 탈주·해방·계약의 맥락을 codex와 연결한다. 30장은 전용 엔딩·해방 지도→잔존 균열 도전·기념비의 의미로 이어진다.
- **완료:** 기존 세계관과 영웅 배경을 지킨다. 첫 감상/다시 보기 구분, 스킵 가능, 반복 승리에서 강제 대화 없음. 기존 4장 오프닝이나 최종 보스·캠페인 수를 임의 교체하지 않는다. 가능하면 stage-clear에서 연출 조건을 유도하고 필요한 감상 상태만 저장한다.

### GD-12 — 해방이 쌓이는 지도

Status: **Partial**. 다섯 지역 원화, 실제 성채 표식, 압축된 경로, 지역 바로가기, 정적 해방 상태와 경로 복구는 구현되었다. 최초 지역 해방 시 한 번만 재생되는 전환 연출은 아직 없다.

- **현재:** 성채 노드·지역 해금·드래그·도전 균열은 구현되어 있다.
- **제안:** 점령 깃발을 왕국/동맹 깃발로 교체하고 해방 지역의 불빛·봉화·길을 복원한다. 지역 승리 뒤 연결선과 다음 지역을 짧게 드러낸다. 상태는 색 외에 형태로도 구분한다.
- **완료:** `clearedStages`에서 올바른 모습을 재구성하고 첫 연출을 반복하지 않는다. 클릭/드래그/스크롤·운영 패널 배치 유지. 미발견 균열·지역 보상 유출 금지. 장식이 터치 표적을 가리지 않는다.

### GD-13 — 병종을 바꿔 쓰게 하는 편성 도구

- **제안:** 기존 계열 필터에 역할·대공·수호·치유·비용·배치 인원 비교를 보강한다. HP 하나로 순위를 매기지 않는다. 다음 단계로 편성 이름과 프리셋을 제공한다.
- **선택 확장:** 보유 병종의 보상 없는 훈련 전장. 별도 세션 유형으로 설계해 골드·XP·조우·업적을 생산하지 않으며 campaign/challenge ID로 위장하지 않는다.
- **완료:** 프리셋은 보유/슬롯 수에 맞게 정규화하고 1~7 순서가 명확하다. 미발견 병종은 검색·비교에서도 비공개. 역할은 canonical capabilities에서 유도한다. 필터·프리셋·훈련장을 단계별로 구분하고 일부만 구현했으면 Partial이다.

### GD-14 — 성장과 획득의 보상 순간

- **현재/문제:** XP와 최초 보상을 표시하지만 전후 변화·새 역할·각성의 시각적 강조를 더할 수 있다.
- **제안:** 새 병종=원화와 역할 한 줄, 영웅=합류 문구, 숙련=전후 레벨과 실제 상승치, 각성/장비 capstone=큰 강조. 작은 골드마다 모달을 띄우지 않는다.
- **완료:** 작은 구매/레벨업/큰 해금의 위계가 다르다. 스킵과 중복 방지가 가능하며 연출 콜백에 지급을 의존하지 않는다. 실제 확정 값과 표시가 같고 최대 레벨에 가짜 성장바를 채우지 않는다.

### GD-15 — 시설의 장소성과 상인의 인물성

- **현재/문제:** 관리 기능은 있지만 카드 중심이며 상인은 물음표 실루엣이다.
- **제안:** 병영=작업대·무기 걸이, 전당=동맹 깃발·초상, 성채=설계도·승급 건물, 상인=오리지널 인물 원화·이동 상점 소품을 상단과 빈 공간에 배치한다. 기술 트리의 데이터 기반 선행 연결은 유지한다.
- **완료:** 장식이 비용·선행 조건·카드를 밀어내지 않고 모바일에서 축약된다. 영웅 훈련은 전당, 상인은 운영 패널 진입을 유지한다. 새 이동형 마을이나 불필요한 로딩을 만들지 않는다. 인물 대사는 짧고 반복 피로 없이 제공한다.

### GD-17 — 전술을 행동으로 배우기

- **현재/문제:** 단축키·설명은 있으나 지휘 대기, 전열, 사각, 대공, 보스 이중 목표를 처음 어떻게 이해하는지는 미검증이다.
- **제안:** 1장 소환·회복, 궁수 획득 뒤 전열, 첫 보스 두 목표, 첫 공중 위협 대공을 상황 안내로 짧게 연결한다. 숙련 전 숨긴 정확한 선딜 수치는 안내로 누설하지 않는다.
- **완료:** 강제 클릭 순서를 따라야 진행되는 방식은 피한다. 터치/키보드 모두 이해 가능, 기존 저장은 건너뛰기, 다시 보기 지원. 안내 노출 횟수보다 실제 행동을 설명/수행할 수 있는지 관찰한다.

### GD-20 — 패배가 다음 선택으로 이어지는 결과

- **현재:** 수치·재도전/지도 버튼·공통 퇴각 문구를 쓴다.
- **제안:** 실제 기록에 근거한 미해결 목표, 병종 숙련 변화, 새 해금과 준비 방향을 요약한다. ‘딜 부족’ 추정 대신 ‘공중 적이 남았다’처럼 계측 가능한 사실을 쓴다. 관측 데이터가 없으면 실패 원인을 단정하지 않는다.
- **완료:** 승리는 해방·획득, 패배는 재편성의 분위기를 주며 전체 통계로 압도하지 않는다. 기본 복귀는 지도, 반복/최초 연출 구분. 기술 집계는 REV-07과 중복 구현하지 않는다.

### GD-21 — 수집품을 쓸 선택형 후반 콘텐츠

- **현재/문제:** 초월 도전과 기념비는 있다. 이를 얻은 뒤 활용할 새로운 전술 목표를 검토할 수 있다.
- **후보:** 클리어 전장에 독립된 수제 도전 규칙을 적용한다. 소수 편성, 공중 위협 중심, 증원 창을 활용하는 공성 등. 순위 경쟁·매일 숙제·무한 HP 증가·계정은 추가하지 않는다.
- **선행:** 입장/승리/이탈/보상/저장/도감/지도 노출 정책을 FUTURE_SYSTEMS에 먼저 설계한다. 영구 능력보다 기록·기념 문양 등의 성취를 우선 검토하되 보상은 아직 확정하지 않는다.
- **완료:** 최소 3개 서로 다른 전략 문제가 실전에서 성립한다. 캠페인·기존 도전·초월 획득 경로를 훼손하지 않는다. 제작 순위 C이며 기본 전투 연출보다 먼저 구현하지 않는다.

### GD-22 — 성장 리듬과 지출 가치

- **현재/문제:** 장비·숙련·연구·훈련·허가·기념비가 많다. 난이도 검사와 실제 반복 횟수·구매 선택의 재미는 다르다.
- **작업:** 균형 투자/집중 투자/영웅 중심 진행의 막힘·재도전·파밍 시간·해금 체감을 기록한다. 무출석/업적 수령 경로의 속도·편성 허가 도달 시점을 나눈다. 기념비 20회 투자도 개별 구매의 체감 가치를 검토한다.
- **완료:** 지루한 반복 구간을 특정하고 수치 변경 전에 해금 안내·효과 미리보기 부족을 분리한다. 무료 숙련/금화 장비 두 축·보석 출처 유지. 변경 시 BALANCE와 감사 갱신. 모든 경로에 필수 투자 비용을 추가하지 않는다.

## 6. UI·플레이 감각

### GD-16 — 전투 정보 우선순위

- **문제 후보:** 최대 7종 카드, 영웅, 포격, 동원, 집결, 속도, 성채·보스 상태가 함께 있다. 작은 화면에서는 위험과 조작 정보가 경쟁할 수 있다.
- **제안:** 상단=승리 목표, 전장=위험·전선, 하단=가능한 명령. 카드 비활성 이유는 지휘 부족/쿨다운/생존 상한으로 구별하고 선택·준비 완료·발동 성공을 다르게 표현한다.
- **완료:** 생존 상한·비용·Q/숫자키·정확한 접근성 쿨다운 유지. 화면에 숫자 소환 카운트다운을 복구하지 않는다. 적 장비·정예 배율·미해금 선딜은 숨긴다. 4/7종과 큰 도전 보스에서 시선 이동·오조작을 검수한다.

### GD-23 — 아이콘·글자·정보 계층

- **현재/문제:** 체스 기호·유니코드·원화·도형이 함께 있다. 게임 고유의 일관된 아이콘 체계가 필요하다.
- **제안:** 금화·보석·지휘·편성·숙련·수호·대공·연구·해방을 같은 선/면 비율의 전용 아이콘으로 정리한다. 작은 기능 아이콘은 SVG 등 코드 친화 자산, 병종·영웅은 기존 atlas 초상을 쓴다.
- **완료:** 숫자/단위, 제목/설명, 현재/변화량 계층이 일관된다. EN/JA 장문에서 잘림·줄바꿈·버튼 폭 검수. 색만으로 상태를 표시하거나 기능 레이블을 전부 무문자 아이콘으로 바꾸지 않는다.

### GD-24 — 연출 강도와 모바일·접근성

- **제안:** 화면 흔들림·플래시·장식 입자를 줄이는 표현 옵션 또는 시스템 모션 축소 대응을 Phaser까지 확장한다. 위험·투사체·HP바는 색 외에 형태로도 구별한다.
- **검수:** 360/390 폭, 가로 모바일, 데스크톱, 텍스트 확대, KO/EN/JA, 1×/1.5×, 최대 편성, 큰 마수, 전투 재입장.
- **완료:** 효과를 낮춰도 필수 위험 신호와 피해 영역을 읽는다. 터치 집결 좌표가 시각 위치와 맞고 손가락이 안내를 가리지 않는다. 표현 옵션은 판정·주기·보상 불변. 포커스는 REV-05와 공유. 저장 설정은 기본값·mute와 관계·전역/슬롯 소유권을 명시한다.

## 8. AI agent 실행·검수 계약

- 구현 전 AGENTS/GAME_SPEC/FUTURE_SYSTEMS와 대상 코드를 읽는다. 판정·진행·수치 변경은 BALANCE도 읽는다.
- 콘텐츠와 조건은 `src/data`, 메뉴/HUD/보상은 React, 전투는 Phaser, 영속 진행은 Zustand 소유.
- 아트·동작만 바꿀 때 HP·사거리·표적·주기·공중 판정·상한은 바꾸지 않는다. 패턴 변경은 별도 수치 설계와 감사 대상이다.
- 아군/적군은 canonical 병종·원화·공통 능력을 공유한다. encounter-only 보스 기능만 명시적으로 분리한다. 정확한 51종/7명·획득 경로·도감 비공개 계약을 보존한다.
- 신규 문구는 KO/EN/JA 계약, 신규 저장 필드는 기본값·import 정규화·구버전 호환성을 따른다. 필요한 경우만 영속 필드를 추가한다.
- 기존 지도 허브·도전 균열·결과→지도 탐색을 유지한다. 새 모드는 정식 설계를 먼저 등록한다.
- 에셋 README에 제작 기록을 남긴다. 원본을 보존하고 오프닝은 versioned sibling으로만 교체한다. 새로운 이미지가 필요한 구현 시점에 이미지 제작 도구를 사용한다. 2026-09-27부터 실제 제작 상태는 문서 상단의 실행 상태에 누적한다.

작업 결과에 필요한 증거:

1. 현재 문제와 기준 화면/영상. 플레이 미확인은 그대로 기록.
2. 구현 범위와 코드·자산 목록, 남은 계획.
3. 동일 장면 전후 비교. 동작·음악을 정지 이미지로만 완료 판단하지 않고 재생 검수 기록 제출.
4. 필요한 최소 회귀 검사와 `yarn lint`, `yarn test`, `yarn build`; 밸런스 변경은 `yarn balance`. 미술 모양·정적 문구 테스트를 불필요하게 늘리지 않는다.
5. 관련 모바일·언어·모션 축소·성능 검수. 공격마다 새 효과 객체를 생성하지 않으며 낮은 효과 수준에도 필수 정보를 유지한다.
6. 실제 동작은 GAME_SPEC, 수치는 BALANCE, 계획 상태는 FUTURE_SYSTEMS와 본 문서에 반영. 일부만 끝나면 Partial.
